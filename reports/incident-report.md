Файл: CA_4624_4625_LogonType2_LogonProc_chrome.evtx
Дата анализа: 20.10.2026
Аналитик: pchillaa
Классификация: ложноположительное срабатывание (false positive)

## Краткое описание инцидента

В журнале Security обнаружена последовательность из 4 событий аутентификации
в окне ~4 секунды. Первая попытка входа завершилась ошибкой (0xC000006A),
последующие - успехом. Все события с Logon Type 2 инициированы процессом
chrome.exe. Нестандартное значение LogonProcessName = Chrome стало поводом 
для проверки.

## Хронология событий

13:18:23.627 - Chrome запрашивает токен доступа для IEUser.
Попытка завершается ошибкой 0xC000006A (неверный пароль). Источник
входа локальный (Source Network Address = -), процесс — chrome.exe
из стандартной директории.

13:18:25.377 - Подключается системная служба services.exe,
выполняет вход от SYSTEM с Logon Type 5 (Service) для подготовки
окружения. Связи с другими сессиями нет (TargetLinkedLogonId = 0x0).

13:18:27.714613 - Chrome успешно получает полный токен 0x1CD8F6
(ElevatedToken = Да), связанный с 0x1CD964. Это первый токен пары,
необходимой для sandbox.

13:18:27.714758 - Chrome получает ограниченный токен 0x1CD964
(ElevatedToken = Нет), связанный с 0x1CD8F6. Интервал между
событиями 137224 и 137225 — 145 микросекунд.

## Вывод

Последовательность событий 137222–137225 с участием chrome.exe
и Logon Type 2 является результатом работы механизма sandbox браузера
Chromium. Признаки компрометации отсутствуют:

- источник входа локальный;
- процесс легитимный;
- временные интервалы (145 мкс) несовместимы с человеческими действиями;
- учётная запись не привилегированная;
- взаимные ссылки Logon ID указывают на пару токенов, а не на два
  независимых входа.

Инцидент классифицируется как ложноположительное срабатывание
(false positive).

## Рекомендации

1) События 4624/4625 с LogonProcessName = Chrome или msedgewebview2 помечать как low severity / false positive, если они не сопровождаются другими индикаторами компрометации.
2) В правилах SIEM фильтровать события от процессов, расположенных в C:\Program Files (x86)\Google\Chrome\ и C:\Program Files (x86)\Microsoft\Edge\.
3) Мониторить 4625 с кодом `0xC000006A` только при наличии внешнего Source Network Address (не `-` и не `127.0.0.1`).
4) Для повышения точности детектирования сопоставлять события 4624/4625 с телеметрией EDR (родительский процесс, подпись бинарника).
5) Учитывать, что при подборе пароля ожидается серия 4625, а не единичное событие — одиночный 4625 в сочетании с легитимным процессом не является индикатором атаки.
