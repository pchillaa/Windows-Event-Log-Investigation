### RU

Это учебный проект по анализу журналов событий Windows. Его цель - отработать методику расследования инцидентов аутентификации и оформить результаты в виде структурированного отчёта.

Объект исследования - Файл "CA-4624_4625_LogonType2_LogonProc_chrome.evtx" из репозитория [EVTX-ATTACK-SAMPLES] (https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES)

Датасет используется в учебных целях для отработки методики анализа журналов событий Windows. Исходный файл не модифицировался.

В качестве инструмента использовался только Windows Event Viewer (eventvwe.msc) и его возможности.


### EN

This is a study project about Windows log file analysis. It's goal is to practice the technique of authentication incident investigation and present the results in a form of a structured report.

Object of investigation is "CA-4624_4625_LogonType2_LogonProc_chrome.evtx" log file from [EVTX-ATTACK-SAMPLES] repository (https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES).

This dataset is used in study terms and to practice analysis techniques of Windows log files and was not modified.

Only Windows Event Viewer (eventvwe.msc) and it's capabilities used as an instrument in this study.
